# HWConditional

`HWConditional` is the abstract base for widgets that pick between two children based on a condition over the widget's data. Use one of the concrete subclasses below; both branches contribute their data dependencies to the generated entry type.

## Variants

### HWDataExists

Renders `whenPresent` if the data field has a value in the widget storage, otherwise `whenAbsent`. A top-level stored field with a `defaultValue` always counts as present — its default is applied when the widget reads its data, so `whenAbsent` never renders — whereas a `defaultValue` on an unsaved `HWJson` leaf does not make it present. Works with any stored [`HWDataType`](/generator/data), as well as an [`HWAppearanceData`](/generator/appearance#conditionals) whose `light` and `dark` sides are stored fields: each side counts as present the way a standalone `HWDataExists` on it would (a top-level stored side with a `defaultValue` on `light` or `dark` always counts as present, so `whenAbsent` never renders; a `defaultValue` on an unsaved `HWJson` leaf does not make it present; a constant side in `iosAccented` or `iosVibrant` is always present; an `HWImageData.asset` side is present when the asset exists). For a runtime [`HWImageData`](/generator/widgets/hw-image) it also checks that the saved picture is still there, so the `whenAbsent` placeholder shows instead of an empty gap.

`HWDataExists({required HWDataType data, required HWWidget whenPresent, required HWWidget whenAbsent})`

### HWBoolConditional

Renders `whenTrue` if the boolean data field is `true`, otherwise `whenFalse`. The `data` must be an `HWBool` (optionally wrapped in `HWJson`, `HWTimedData`, or `HWItemData`) **with a non-null `defaultValue`**, or an [`HWAppearanceData`](/generator/appearance#conditionals) of `HWBool` values (whose sides do not require a `defaultValue` and may use `HWBool.fixed`).

`HWBoolConditional({required HWDataType data, required HWWidget whenTrue, required HWWidget whenFalse})`

## Example

```dart
HWDataExists(
  data: HWBool('hasData'),
  whenPresent: HWBoolConditional(
    data: HWBool('data', defaultValue: true),
    whenTrue: HWText(
      HWString.fixed('Enabled'),
      style: HWRoleTextStyle.headline(color: HWColor.fixed(0xFF00FF00)),
    ),
    whenFalse: HWText(
      HWString.fixed('Disabled'),
      style: HWRoleTextStyle.headline(color: HWColor.fixed(0xFFFF0000)),
    ),
  ),
  whenAbsent: HWText(HWString.fixed('No Data')),
)
```

The condition must be a stored field (or an `HWAppearanceData` as described above). A bare [fixed value](/generator/data#fixed-values) such as `HWBool.fixed(true)` or `HWString.fixed('x')` is a generation error as the `data` of either variant, because one branch could never render. To pin a branch while you work on a layout, give the stored `HWBool` a `defaultValue` and `previewValue`.

## Parameters

### HWDataExists

| Name          | Type           | Default      | Description                                   |
| ------------- | -------------- | ------------ | --------------------------------------------- |
| `data`        | `HWDataType`   | **required** | Field (or `HWAppearanceData`) whose presence is tested. |
| `whenPresent` | `HWWidget`     | **required** | Rendered when the field has a value.          |
| `whenAbsent`  | `HWWidget`     | **required** | Rendered when the field is `null`/missing.    |

### HWBoolConditional

| Name        | Type           | Default      | Description                                              |
| ----------- | -------------- | ------------ | -------------------------------------------------------- |
| `data`      | `HWDataType`   | **required** | An `HWBool` (or wrapped `HWBool`) with a `defaultValue`, or an `HWAppearanceData` of `HWBool` values. |
| `whenTrue`  | `HWWidget`     | **required** | Rendered when the value is `true`.                       |
| `whenFalse` | `HWWidget`     | **required** | Rendered when the value is `false`.                      |

## Platform mapping

- **iOS:** generates a SwiftUI `if / else` expression in the view body — see [SwiftUI `ViewBuilder`](https://developer.apple.com/documentation/swiftui/viewbuilder).
- **Android:** generates a Kotlin `if / else` expression in the Glance composable — see [Glance composables](https://developer.android.com/reference/kotlin/androidx/glance/package-summary).
