# HWText

Renders a string, a number, or a date. The value is a data type: a stored field that your app saves at runtime, or a fixed value written into the schema. Every constructor accepts an optional [`HWTextStyle`](/generator/styling/hw-text-style) and `HWTextAlign`.

## Constructors

### HWText

`const HWText(HWDataType data, {HWTextStyle? style, HWTextAlign? textAlign})`

Renders the value of a data type. A stored type such as `HWString('greeting')` reads from widget storage at runtime; add the matching field to the entry by using it here or via [`HWDataOnly`](/generator/widgets/hw-data-only).

```dart
HWText(HWString('greeting'))
```

For constant text, use `HWString.fixed`. The value is baked into the generated native code and creates no data field.

```dart
HWText(HWString.fixed('Hello World'))
```

For text translated at build time, use `HWString.localizedFixed`. It maps locale tag to text and must cover
every entry of `supportedLocales`, including the widget's `defaultLocale`. It
creates no data field and cannot be overridden at runtime — it ships as a
platform string resource and is resolved by the OS.

```dart
HWText(
  HWString.localizedFixed({
    'en': 'Greeting',
    'de': 'Begrüßung',
    'pt-BR': 'Saudação',
  }),
)
```

This requires a `localization:` block on the annotation. For text your app can change
per locale at runtime, bind `HWString.localized` instead — see
[Localization](/generator/localization).

A number or a date passed to the default constructor is formatted for the device locale: `HWText(HWInt('count'))` is the same as `HWText.number(HWInt('count'))`, and `HWText(HWDateTime('lastSync'))` the same as `HWText.dateTime(HWDateTime('lastSync'))`. See [Formatting](/generator/formatting).

### HWText.number

`const HWText.number(HWDataType<num> data, {HWNumberFormat format = const HWNumberFormat.decimal(), HWTextStyle? style, HWTextAlign? textAlign})`

Renders a number formatted for the device locale — grouping and
decimal separators, percentages, currencies, compact forms. `data` must be an
`HWInt` or `HWDouble`, optionally wrapped in `HWTimedData`, `HWJson` or, inside
a [list item](/generator/lists), `HWItemData`.

```dart
HWText.number(HWDouble('total'), format: HWNumberFormat.currency(currency: HWCurrency.code('EUR')))
```

For a constant number, pass `HWInt.fixed` or `HWDouble.fixed`. The value is baked into the generated code, the
formatting still happens on the device.

```dart
HWText.number(HWInt.fixed(10000))
```

### HWText.dateTime

`const HWText.dateTime(HWDataType<DateTime> data, {HWDateFormat format = HWDateFormat.defaultFormat, HWTimeZone timeZone = HWTimeZone.local, HWTextStyle? style, HWTextAlign? textAlign})`

Renders an [`HWDateTime`](/generator/data) value in the device's locale and,
by default, the device's time zone. `data` must be an `HWDateTime`, optionally
wrapped in `HWTimedData`, `HWJson` or, inside a [list item](/generator/lists),
`HWItemData`. Pass `timeZone` to show a fixed or
per-record zone instead — see [Time zones](/generator/formatting#time-zones).

```dart
HWText.dateTime(HWDateTime('lastSync'), format: HWDateFormat.yMMMd)
```

For a constant date, pass `HWDateTime.fixed` a UTC ISO 8601 string:

```dart
HWText.dateTime(HWDateTime.fixed('2026-09-22T10:00:00Z'), format: HWDateFormat.yMMMd)
```

A fixed value creates no stored field and cannot be wrapped in `HWTimedData`, `HWJson` or `HWItemData`. See [Fixed values](/generator/data#fixed-values).

All three are covered in detail on [Formatting](/generator/formatting).

### Styled example

```dart
HWText(
  HWString.fixed('46'),
  style: HWRoleTextStyle(
    role: HWTextStyleRole.title,
    color: HWDefaultColor(HWColorRole.contentPrimary),
    fontWeight: HWFontWeight.bold,
  ),
)
```

## Parameters

| Name           | Type            | Default      | Description                                                  |
| -------------- | --------------- | ------------ | ------------------------------------------------------------ |
| `data`         | `HWDataType`    | **required** _(default ctor)_ | Value that is rendered: a stored field, `HWString.fixed` or `HWString.localizedFixed`. |
| `data`         | `HWDataType<num>` | **required** _(`.number`)_ | Number to format — `HWInt` / `HWDouble`, fixed or stored, optionally wrapped. |
| `data`         | `HWDataType<DateTime>` | **required** _(`.dateTime`)_ | `HWDateTime` to format, fixed or stored, optionally wrapped. |
| `format`       | `HWNumberFormat` | `HWNumberFormat.decimal()` _(`.number`)_ | How the number is rendered — see [Formatting](/generator/formatting). |
| `format`       | `HWDateFormat`  | `HWDateFormat.defaultFormat` _(`.dateTime`)_ | How the date is rendered — see [Formatting](/generator/formatting). |
| `timeZone`     | `HWTimeZone`    | `HWTimeZone.local` _(`.dateTime`)_ | Zone the date is displayed in — see [Time zones](/generator/formatting#time-zones). |
| `style`        | `HWTextStyle?`  | `null`       | Font, weight, color — see [`HWTextStyle`](/generator/styling/hw-text-style). |
| `textAlign`    | `HWTextAlign?`  | `null`       | Multi-line text alignment.                                   |

The type of `data` decides whether the value is stored or constant. A `.fixed` value is written into the generated code and adds no `saveData` or `getData` parameter.

## Platform mapping

- **iOS:** SwiftUI [`Text`](https://developer.apple.com/documentation/swiftui/text), with `.multilineTextAlignment(...)` when `textAlign` is set.
- **Android:** Glance [`Text`](https://developer.android.com/reference/kotlin/androidx/glance/text/package-summary#Text(kotlin.String,androidx.glance.GlanceModifier,androidx.glance.text.TextStyle,kotlin.Int)) with a [`TextStyle`](https://developer.android.com/reference/kotlin/androidx/glance/text/TextStyle).
