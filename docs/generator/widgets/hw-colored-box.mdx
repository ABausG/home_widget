# HWColoredBox

Paints its area with a single color and renders a child on top. For backgrounds with a border or rounded corners use [`HWDecoratedBox`](/generator/widgets/hw-decorated-box).

```dart
HWSizedBox.expand(
  child: HWColoredBox(
    color: HWColor.fixed(0xFF0000FF),
    child: HWSizedBox.expand(
      child: HWColumn(
        children: [
          HWText(HWString.fixed('No Color')),
          HWText(
            HWString.fixed('Fixed Color'),
            style: HWTextStyle(color: HWColor.fixed(0xFFFF0000)),
          ),
          HWText(
            HWString.fixed('Appearance'),
            style: HWTextStyle(
              color: HWAppearanceData(
                light: HWColor.fixed(0xFFFFFF00),
                dark: HWColor.fixed(0xFF00FFFF),
              ),
            ),
          ),
        ],
      ),
    ),
  ),
)
```

`color` accepts any color value: a stored [`HWColor`](/generator/styling/hw-color), `HWColor.fixed`, `HWDefaultColor`, a color wrapped in `HWJson`, `HWTimedData`, or `HWItemData`, or an [`HWAppearanceData`](/generator/appearance) of colors. When a stored color has no value and no `defaultValue`, the box draws transparent and keeps its layout.

## Parameters

| Name    | Type              | Default      | Description                                                      |
| ------- | ----------------- | ------------ | ---------------------------------------------------------------- |
| `child` | `HWWidget`        | **required** | The widget painted on top of the color.                          |
| `color` | `HWDataType<int>` | **required** | Any color value. See [`HWColor`](/generator/styling/hw-color).   |

## Platform mapping

- **iOS:** SwiftUI [`.background(_:)`](https://developer.apple.com/documentation/swiftui/view/background(_:ignoressafeareaedges:)) modifier.
- **Android:** Glance [`Box`](https://developer.android.com/reference/kotlin/androidx/glance/layout/package-summary#Box(androidx.glance.GlanceModifier,androidx.glance.layout.Alignment,kotlin.Function1)) with [`GlanceModifier.background(...)`](https://developer.android.com/reference/kotlin/androidx/glance/package-summary#background(androidx.glance.GlanceModifier,androidx.glance.unit.ColorProvider)).
